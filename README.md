# Israeli IPTV maintenance
Upload all files (including hidden .github directory) to your existing repository root. Enable Actions and allow workflow write permissions if required. Run Daily IPTV maintenance manually from Actions. Keep your existing raw israel.m3u URL. On CachyOS install ffmpeg and python, create a virtual environment and install requirements.txt; run python maintain.py in that environment.

The initial playlist is cleaned, not verified. Only use streams you are authorized to access. Public indexes do not establish licensing; review candidate sources. The official_urls config maps exact tvg-id to a list of reviewed URLs. Radio discovery uses exact Radio Browser UUID; fallback IDs require manual mapping. TV discovery uses exact tvg-id; aliases require manual mapping. Foreign-runner 403/451, connection failures and timeouts remain uncertain and are retained; set foreign_runner false only on an authorized local runner. Mass failure freezes both playlists and skips replacement discovery. Daily status reports still change. FFprobe checks packets, not full decoding or TV compatibility. No live network tests were performed during creation. GitHub schedules may be delayed or disabled after inactivity; private repositories have usage limits. Existing stream metadata is preserved except replacement-specific HTTP options are removed. Do not publish private tokens or credentials. Review the report after the first run.
